
# SwiftUI Playground

An incremental iOS project focused on mastering SwiftUI,
modern architecture, and software engineering best practices.

## Project Overview

This project explores modern iOS development through the
incremental implementation of a personal profile application.

## Tech Stack

- Swift
- SwiftUI
- Xcode
- Git & GitHub

## Learning Roadmap

- [x] Project setup and version control
- [x] Basic SwiftUI views
- [ ] View modifiers and layouts
- [ ] State management
- [ ] Data binding
- [ ] Navigation
- [ ] MVVM architecture
- [ ] Networking with async/await
- [ ] Data persistence
- [ ] Unit and UI testing
- [ ] CI/CD with GitHub Actions

## Getting Started

1. Clone the repository.
2. Open SwiftUIPlayground.xcodeproj in Xcode.
3. Select an iOS simulator.
4. Build and run the application.
